How the pool works

  1. Public visitors never see or enter a token.
  2. Each build reserves one free slot on the healthiest token.
  3. If a slot fails, the next account is tried automatically until the build is live.
  4. A rejected token is marked and skipped until you re-check it.
  5. Slots free up automatically when a build finishes or fails.
